# 🏨 Luxury Hotel Reservation & Management System

An end-to-end Database Management System developed as part of the Database Systems (DBS) module.

## 🚀 Features
* **Role-Based Portals:** Secure login and registration for **Customers** and **Receptionists**.
* **Customer Portal:** Browse and reserve rooms, manage pre-arrival modifications, and view booking statuses.
* **Receptionist Dashboard:** Front desk operations, quick check-ins (using OTP/QR workflows), and automated billing/stay extensions.
* **Database Management:** Fully normalized database schema handling users, rooms, bookings, and payments.

## 🛠️ Tech Stack
* **Frontend / Backend:** PHP, HTML, CSS, Tailwind CSS
* **Database:** MySQL / phpMyAdmin
* **Tools & Workflow:** AI-assisted rapid prototyping and system architecture design.

## 📂 Database Setup
1. Import the `luxury_hotel_db.sql` file into your local MySQL server (via phpMyAdmin).
2. Configure your database connection in `db.php`.
3. Run the project on a local server (like XAMPP).
